HireMe – MERN Stack Job Portal

HireMe is a job portal application developed using the MERN Stack. It connects students and job seekers with recruiters and helps them explore job opportunities and manage applications.

Technologies Used

- React.js – Frontend
- Node.js – Backend runtime
- Express.js – Backend framework
- MongoDB – Database

Features

- User registration and login
- Student dashboard
- Student profile management
- Resume upload
- Browse job opportunities
- Apply for jobs
- Recruiter dashboard
- Post and manage job openings
- View applicants

Project Structure

- "client/" – Frontend application
- "server/" – Backend application

Installation

1. Clone the repository.
2. Install frontend dependencies.
3. Install backend dependencies.
4. Configure environment variables.
5. Start the frontend and backend servers.
